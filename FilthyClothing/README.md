## Filthy Clothing

Mod that reimplements filthy clothing to the game.

Filthy clothing occurs in two ways:
- Worn clothing over time ( non-applicable to NPCs )
- Zombies on the ground

In addition it reimplements some of the negative filthy clothing traits with a few additions.

## Other Mod Compatibility

### Enchantments

#### DUCK_CLOTHING_MORALE

Alters the amount of morale gained or lost by clothing.

| Set      | Values                                 | Use                                         |
| -------- | -------------------------------------- | ------------------------------------------- |
| Cleanliness | DIRTY, NORMAL, CLEAN | Weather it affects (dirty), flagless or clean clothes |

#### DUCK_CLOTHING_TIME_DIRTY

Alters the amount of time it takes for clothing to become dirty.
