## What is this?

Collection of all of my cataclysm mods. Stored in one repo for my sanity

## Brief Mod Description

### Filthy Clothing

Reintroduces filthy clothing, with currently mild morale penalties when dirty and bonuses when clean.

Clothing becomes filthy over time, and at the point any creature dies all clothing becomes dirty.

Cleaning can be done via a few items and the furniture washing machine.

Also adds a few enchantment values which mods can hook onto to change how sever filthy clothing effects are.

### Duck Perks

A version of bombastic perks for bright nights, currently with less perks then the other version, there are some completely new ones too

Both utilizes the perks system, and provides a multitude of custom enchantmment values and enchantment conditions

## What game version is this compatible with?

All mods require the latest nightly, or versions prefixed with the number of the stable release minus 1
are compatible with that stable release ( I.E. 12.0.1 mod version is compatible with stable 13.0.0 )

Fixes will not be backported to stable compatible versions.
